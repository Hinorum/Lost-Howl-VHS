## 1. Каркас месяца (ритм по Промпту Б)

| Блок | Дни | Содержание |
|---|---|---|
| Зачин | 1–11 | Край кратера, снег, входные билеты (кто стая, что за стук из-под земли, кто говорит). Необратимых развилок месяца нет |
| Нарастание | 12–18 | Первые спуски, катакомбы, находка: таймер — не бомба, а **записывающая машина** (считает и вырезает имена) |
| Поворот | **19** | Статус меняется: стая **записана** — на стене уже есть имя щенка, которого стая потеряла в исходе |
| Накал | 20–27 | Ложь вожака вскрывается (д.23 — этика-2), щенок уходит вниз сам (д.24), приготовление к финалу |
| Кульминация | 28–29 | **Один** день, где три карты — три судьбы месяца (на main это д.28) |
| Развязка | 29–31 | Расплата и равновесие; новых вопросов нет |

- **Единая цена месяца:** укрытие в балке — единственное, что стая держала
  всю зиму, — отдаётся в кульминации. «Все довольны» развязкой не бывает.
- **Этические дни:** **д.7** (первая половина: чужая семья у порога —
  пустили/выгнали/поделились) и **д.23** (вторая: сказать стае о лжи вожака /
  утаить / свалить на голос из-под земли). Ни одна карта не «правильная».
- **Сквозной мотив с выплатой — колокольчик на ошейнике щенка:**
  - завести д.3: щенок звенит на каждом шагу (герой не понимает, зачем);
  - удивить д.9: внизу **отвечает** другой звон — не ветер и не эхо;
  - выплатить д.31: последний звон — это и есть цена/спасение (ответ первому дню).

## 2. Голоса стаи (3–5, ≥2 появлений, один — в накале)

1. **Старшина** — вожак-скромник; несёт решение и **врёт** (таймер растёт —
   утаил с д.12; ложь вскрывается в д.23). Речь: короткая, «я знал».
2. **Копёр** — ворчун-инженер (архетип Рекса, не он сам): чертежи, лестницы,
   «красивая палка». В накале — д.25, единственный, кто считал остаток честно.
3. **Крошка** — щенок-летописец, POV дневника; потерял брата в исходе.
4. **Шепот** — хитрец-торговец: ведёт переговоры с Голосом, trick-голос.
5. **Бабка Тряпка** — ворчуха-погодница, комический фон; возвращается в
   сильной точке (д.26 — «я ещё при своих умах»).

ротировки (каждая стратегия ≥3 раз в каждой позиции, не 3 дня подряд).

## 4. Перемотки (2 шт., арифметика)

- `at_day = 27` (последняя треть: 31−10…31−3 ✓); день 26 — вход.
- `switch A`: `winner=1` → дорога **«Яма»** (д.27–31, 5 дней) — dare-судьба
  (вглубь, цена — не вся стая вернулась).
- `switch B`: `winner=2` → дорога **«Тропа»** (д.27–31, 5 дней) — trick-судьба
  (чужие имена, стая «ненастоящая» в записи, но выходит вся).
- `main` — care-судьба (заглушка, дом отдан снегу) — прописывается полностью.
- Объём: 31 + 5 + 5 = **41 ≤ 1.5×31** ✓. Разные `winner` ✓, дублей пар нет ✓.
- **Сходимость:** на всех дорогах д.29–31 — один вопрос «что такое дом»,
  разные ответы; д.31 — общее равновесие + выплата колокольчика.
- На первом дне каждой дороги (д.27) в `prev` — **только ключ победителя
  д.26**, равный `winner` перемотки.

## 5. Дневник (`diary`, POV Крошки)

## 8. Чек-лист самопроверки (до `validate_file`)

1. Дней = 31, `day_index` 1..31 на каждой дороге.
2. 3 карты/день, care/dare/trick, все честные кандидаты, имена-поступки, без
   дублей имён внутри дороги.
3. Ротировка позиций: каждая стратегия ≥3 раз в каждой позиции, не 3 дня
   подряд в одной.
4. `prev`: ≥N/3 привязок по main, все 3 ключа в д.20/28, только ключ
   победителя в д.27 каждой дороги; `any` не использовать (0 дней).
5. Мотив колокольчик: д.3 → д.9 → д.31 (выплата); цена — укрытие в балке.
6. Этические дни: д.7 и д.23.
7. Станции уникальны внутри дорог; последняя треть — 3 разных места.
8. Стоп-слова отсутствуют (woof/notcoin/$not/$bones/токен/доход/официальн…);
   чисел комьюнити/банков/ставок нет; слов закона («решат», «голосуют»,
   «большинство»…) нет ни в одном поле; `consequence` — как свершившееся.
9. Голоса: 5 голосов, ≥2 появления, Копёр — в накале (д.25).
10. Перемотки: 2, `at_day=27`, разные `winner`, объём 41 ≤ 46.5, сходимость
    д.29–31.
11. `attribution` проставлен.
12. Ни одна строка невыбранного черновика не повторяется в последующих сценах.
